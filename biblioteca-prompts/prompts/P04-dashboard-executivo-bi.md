# P04 — Dashboard executivo (BI)
**v1.0 · 29/09/2026** · Categoria: **Business Intelligence** · Persona: Especialista em Business Intelligence
**Origem:** imagem enviada pelo Alexandre (lote 1). Autor original não identificado.

## Quando usar
Uma planilha com séries históricas e dimensões para filtro (período, unidade, produto, região).

## Prompt (transcrito sem alterações)
```text
Você é um especialista em Business Intelligence. Analise toda a planilha enviada e transforme os dados em um dashboard executivo para a diretoria.

Crie:
• 8 KPIs principais
• Gráficos de evolução
• Comparativos entre períodos
• Filtros relevantes
• Alertas para desvios importantes

No final, destaque os 5 números que mais exigem uma decisão da diretoria.
```

## Dicas de uso *(nota do curador — não faz parte do prompt original)*
- Diga o formato de saída desejado (HTML interativo, Excel, descrição para montar no Power BI).
- Defina o que conta como “desvio importante” (ex.: variação > 10% vs. mês anterior ou vs. meta).
- Anexe os arquivos junto com o prompt. Confira os números da resposta na fonte antes de usar com cliente ou diretoria.
