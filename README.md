# Guia de Alocação PG

Ferramenta HTML única e offline para montar, em reunião, a alocação de um cliente a partir da política Alocação PG (InvestSmart/XP). Entregável: `80-producao/guia-alocacao.html`.

## Por onde começar (sessão nova)
1. Leia `CLAUDE.md` (memória canônica: regras, identidade, protocolo).
2. Leia `INDEX.md` (estado atual: versões, fase, pendências).
3. Só então trabalhe. Ao terminar, rode o Protocolo de Auto-Atualização (fim do `CLAUDE.md`).

## Regra que precede tudo
Não é recomendação de investimento; não substitui suitability. Dado não confirmado é sempre marcado, nunca apresentado como certo. Ver `CLAUDE.md` §0.

## Estado em uma linha
Funcional e testado. O que falta é confirmação de dados do mundo real (ver `BACKLOG.md`, P0), não código.
